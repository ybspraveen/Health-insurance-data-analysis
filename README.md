# Health Insurance Data Analysis

## 📌 Project Overview
This project analyzes a health insurance dataset to identify factors affecting medical insurance costs.

## 🛠️ Tools Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Jupyter Notebook

## 📊 Dataset
- 1,338 records
- 7 features: age, sex, bmi, children, smoker, region, charges

## 🔑 Key Findings
- **Smoking** is the most significant factor affecting insurance costs
- **Age** and **BMI** also have a strong impact
- Smokers pay significantly higher premiums

## 📈 Visualizations
- Histograms, Scatter Plots, Box Plots, Heatmaps
